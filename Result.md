# Отчет о проведенном тестировании

При выполнении тестирования приложения "Мобильный хоспис" получены следующие результаты:

- Составлен чек-лист для быстрой проверки главных функций и условий использования приложения. 
- Составлено 53 тест-кейса, охватывающих основные функциональные возможности приложения.
- Написаны 34 автотеста, которые обеспечивают уменьшение необходимого времени тестирования и ускорение процесса проверки качества функционала приложения.
- Успешно пройдены 32 из 34 авто-тестов.
- Составлено 3 баг-репорта, описывающих найденные ошибки приложения.
- К проекту подключен инструмент Allure для генерации отчетов о результатах тестирования.

### Сравнение результатов ручного и автоматизированного тестирования.
1. Время выполнения `ручного тестирования` - 1,5 часа
- Ручное тестирование позволяет получить, условно, мгновенный результат на проведенный тест, но в долгосрочной перспективе будет занимать все больше времени на проверку уже имеющегося функционала приложения.
- При использовании ручного тестирования могут возникать ошибки связанные с усталостью и снижением внимания сотрудника, проводящего тестирование.
2. Время выполнения `автоматизированного тестирования` - 6 минут
- Автоматизированное тестирование на стадии подготовки и написания тестов проекта может занять длительное время, однако в дальнейшем поможет сэкономить в десятки раз больше времени на повторных стадиях тестирования.
- При использовании автоматизированного тестирования исключается человеческий фактор, влияющий на  точность проведения тестов.
- Использование CI/CD на проекте с помощью автотестов позволяет добиться непрерывного процесса тестирования при добавлении новых функциональных возможностей приложения.

### Заключение

По итогам проведенного тестирования выявлены проблемы, требующие внесения правок для нормальной работы приложения. 

Рекомендуется увеличить тестовое покрытие для более полной проверки качества работы приложения и рассмотреть возможность внедрения CI/CD процессов для быстрого контроля новых сборок приложения.
